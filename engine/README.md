# Engine

| File | What it does |
| --- | --- |
| `studio.py` | The engine and its commands. Run `python studio.py --help`. |
| `scene.py` | Renders only the slides that the engine asks for. |
| `scene_gx.py` | Runs `scene.py` with ManimGX in place of Manim CE. |
| `present.py` | The presenter of Manim Slides, with a correct full screen mode. |
| `panel.html` | The web panel. |
